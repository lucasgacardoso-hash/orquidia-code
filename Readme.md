# DevSul Conf

## 📌 Sobre o evento

O **DevSul Conf** é um evento fictício de tecnologia com foco em **Desenvolvimento Web e Inteligência Artificial**. A proposta desta página é divulgar o evento, apresentando sua programação, palestras, workshops e informações para os participantes.

Este projeto foi desenvolvido de forma colaborativa utilizando **Git e GitHub**, com divisão de tarefas em branches, Pull Requests e revisão entre a equipe.
